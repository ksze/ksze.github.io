BOOTH B-01OPEN

ZhangJing

Bring-your-own-key LLM translation. Paste your text, pick any provider and model, translate with your API key. Everything runs client-side; the key never leaves your browser. Swap translation and text-to-speech providers on the fly; listen to or download the result.

The proof: real multi-provider LLM integration with zero backend: the whole product is the browser tab.

BOOTH B-02OPEN

PeerAuth

A hedge against AI deepfakes: when a voice and a face can be forged, how do you know the person on the phone is real? PeerAuth lets two people set up a shared TOTP secret in person (scan, verify, done), so any future call or video chat can be confirmed with a 6-digit code. No accounts, no server holding your tokens; the whole mechanism lives on the page and in the public source.

The proof: security mechanics done client-side: cryptography as a static page, not a service.

Xuanzang

Learn geography and history by travelling. Follow Xuanzang’s seventh-century journey from Chang’an along the Silk Road on an animated map: step-through journey lessons that draw the route as you go, place quizzes built from researched historical geography, and present-day context at every stop. Fully bilingual, English and 中文.

ClusterMob

A community registry of Hermes agent profiles and profile packs — publish what you have built, browse and search what others have, all backed by a public REST API documented with OpenAPI. Unlike the other booths on this floor, this one is a full production product: frontend, backend, database, and deployment, running at clustermob.com.

The engineer behind the floor

I’m Ka Lun “Kal” Sze, a senior software engineer in Calgary. For five years I built the backends behind industrial energy-sector platforms at Avaxia Group: TypeScript and Node services that handled real operational data at scale, under audit. Before that: machine-learning infrastructure for retail video analytics.

I work agent-first: this entire floor was designed and shipped with an AI agent (Hermes) as my implementation partner, the same way I built every project above. The stack range is wide on purpose (TypeScript, Python, Rust, Erlang/OTP) because the interesting problems rarely stay in one language.

Everything on this floor is real, running, and public. Walk into any booth; the source is the résumé.
